References & Resources

The sources behind this research. All pages were accessed September 2, 2026.

References

  1. MDN Web Docs (Mozilla). "Evolution of HTTP." MDN Web Docs. https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Evolution_of_HTTP Used for: features and dates of each HTTP version, RFC numbers, and SPDY.
  2. MDN Web Docs (Mozilla). "An overview of HTTP." MDN Web Docs. https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview Used for: clients, servers and proxies, request and response structure, methods, status codes, headers, statelessness and cookies.
  3. Amazon Web Services. "What's the Difference Between HTTP and HTTPS?" AWS. https://aws.amazon.com/compare/the-difference-between-https-and-http/ Used for: why plain HTTP is insecure, HTTPS and TLS, ports 80 and 443, and certificates.
  4. Cloudflare. "HTTP/2 vs. HTTP/1.1: How do they affect web performance?" Cloudflare Learning Center. https://www.cloudflare.com/learning/performance/http2-vs-http1.1/ Used for: multiplexing, prioritization, server push, header compression, and HTTP/1.1 blocking.
  5. Cloudflare. "Cloudflare and the IETF." The Cloudflare Blog. https://blog.cloudflare.com/cloudflare-and-the-ietf/ Used for: the role of the IETF and how internet standards are made.
  6. F5, Inc. "QUIC and HTTP/3." F5 Glossary. https://www.f5.com/glossary/quic-http3 Used for: QUIC over UDP, built-in TLS 1.3, fewer round trips, head-of-line blocking, and connection migration.
  7. CERN. "A short history of the Web." CERN. https://home.cern/science/computing/the-birth-of-the-web/short-history-web/ Used for: Tim Berners-Lee's 1989 proposal, the first server and website, and the 1993 royalty-free release.
  8. Internet Engineering Task Force (IETF). RFC 1945, RFC 2068, RFC 2616, RFC 7230–7235, RFC 7540, RFC 8446, RFC 9000, RFC 9110–9112, RFC 9114. RFC Editor. https://www.rfc-editor.org/ Used for: checking the publication dates and RFC numbers for each version of HTTP, TLS 1.3 and QUIC.

Learning Resources

If you want to go further, these are good places to start. They come from the same organizations used in the research above.

  • MDN Web Docs – HTTP – Mozilla's full HTTP section, including reference pages for every method, status code and header.
  • MDN – An overview of HTTP – the best beginner explanation I found of how requests and responses work.
  • Cloudflare Learning Center – short, readable articles on HTTP, DNS, TLS and networking.
  • The first website (info.cern.ch) – the original page from 1990/91, still online at its original address.
  • RFC 9110 – HTTP Semantics – the current official definition of methods, status codes and headers. It's long, but it's the real source.

Try it yourself

You can see real HTTP traffic in any browser. Press F12 to open developer tools, go to the Network tab, reload the page, and click a request to see its method, status code and headers. If you have a terminal, curl -v https://example.com/ prints the whole request and response.
