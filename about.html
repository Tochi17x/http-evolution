About This Project

This website was created for IT 3203 – Introduction to Web Development at Kennesaw State University as Project Milestone #1. It explores the history and development of HTTP, the protocol that lets web browsers and servers communicate.

The research comes from my Assignment #1 presentation, The Evolution of HTTP: How the Web Communicates. For this project I took that material and rewrote it as a multi-page website. The sources are listed on the References & Resources page.

The site was built by hand with:

  • Six HTML pages using semantic elements like <header>, <nav>, <main>, <section> and <footer>
  • One external stylesheet, styles.css, shared by every page
  • Flexbox for the navigation bar and CSS Grid for the key terms on the home page
  • No JavaScript and no CSS frameworks

This website is a student project created for IT 3203 – Introduction to Web Development at Kennesaw State University.
